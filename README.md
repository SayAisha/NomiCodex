# NomiCodex

Unofficial recipe browser for the **NomiFactory CEu** Minecraft modpack (normal + expert modes).

- Search every item, fluid and recipe; view machine recipes with EU/t, durations and heat
- Overclock calculator (ported from the oceu tag)
- Light/dark themes, deep links (`?item=`, `?mode=`, `?theme=`)

## Data

Item and recipe data is exported from Nomi CEu 1.7.7. Recipe card images under `cards/`
are rendered from the game's own item textures.
