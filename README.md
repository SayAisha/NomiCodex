# NomiCodex

Unofficial recipe browser for the **NomiFactory CEu** Minecraft modpack (normal + expert modes).

- Search every item, fluid and recipe; view machine recipes with EU/t, durations and heat
- Overclock calculator (ported from the oceu tag)
- Light/dark themes

## Data

Item and recipe data is exported from Nomi CEu 1.7.7. Item textures are grabbed from the
game using the icon rendering pipeline from
[susy-factory-flow](https://github.com/SymmetricDevs/susy-factory-flow).
